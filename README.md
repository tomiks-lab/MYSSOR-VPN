# MYSSOR VPN — стартовый проект

Это стартовый Telegram-бот: меню, выбор тарифов, профиль, SQLite и базовая админ-панель.

**Пока не готов к приёму платежей:** Rolly Pay и автоматическая выдача VPN-ключей не подключены. Админ-разделы частично являются заглушками. Не принимайте оплату до интеграции и тестирования.

## Запуск на Ubuntu 24.04
1. Скопируйте `.env.example` в `.env`.
2. Впишите токен Telegram-бота в `BOT_TOKEN`.
3. Запустите: `docker compose up -d --build`
4. Логи: `docker compose logs -f bot`

Не публикуйте `.env`, токены, пароли, SSH-ключи и реальные VPN-конфиги в GitHub.
